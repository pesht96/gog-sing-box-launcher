This package is generated for the remote update pipeline. Publish only after
the router-side updater has passed the required verification gates.

v2.45 keeps a reachable but slow provider pool from turning into repeated
watchdog recovery work. On proxy failure, watchdog uses a bounded short
per-node YouTube quality sample, keeps the existing runtime when the pool is
reachable but below the usable throughput threshold, and never invokes the
full manual Ping action. A qualified replacement changes only the live
AUTO-BALANCE selector. User subscriptions, selected nodes, manual domains,
and settings are preserved.
